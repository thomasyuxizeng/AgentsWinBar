# README media

Every image and animation here was captured from the app running in developer mode on invented sample data (fictional
numbers, plan names and a "You" / "Teammate" API-credits split). None of it is real usage. US English alt text, one line
on what each file shows.

| File | Alt text | What it shows |
|------|----------|---------------|
| `overview.png` | Flyout, detail page and taskbar strip | The tray flyout (Claude at its limit with a red outage dot, Codex with an amber incident dot), Gemini's detail page with its usage history chart, and the taskbar strip below. |
| `flyout.png` | The flyout: Claude at its limit with a red outage dot, Codex with an amber incident dot | The flyout's provider cards and footer buttons (dashboard, refresh, settings). |
| `dashboard.png` | The dashboard with a limit reached, an outage, a service incident and API credits running low | Needs-attention summary and the three provider panels: Claude session at 100%, Codex session at 93% ahead of pace, Gemini External 7d near its limit, API credits running low. |
| `dashboard-graphs.png` | The GRAPHS section with a burndown chart for every usage window | One card per provider with usage against an even-use guide and a dashed projection; red for the windows ahead of pace, amber for External 7d (Diagnostics strip cropped off). |
| `overlay.png` | The floating overlay | The always-on overlay: one row per provider, two bars each, with the status dots on the Claude and Codex logos. |
| `taskbar-strip.png` | The taskbar strip | The same readout laid out as the strip along the taskbar. |
| `settings.png` | Settings | The whole Settings window, captured at three scroll positions and joined into two columns without gaps (Appearance, Providers, costs and API budget, Sign-ins, Behavior). |
| `signed-out.png` | A provider panel showing the Signed out banner with its Sign in button | The dashboard's Codex panel when its sign-in is gone: the banner and button, with the last known numbers dimmed. |
| `settings-signins.png` | Settings, Sign-ins: Codex signed out, the others signed in | The Sign-ins section of Settings with one provider showing Signed out and its Sign in button. |
| `reset-overlay.gif` | A reset animation on the floating overlay | Claude's session bar at 100% resets: the ring draws, the fill turns green and collapses, a glow sweeps across (about 4 s, loops). |
| `reset-dashboard.gif` | A reset animation on a dashboard card | The same animation on the dashboard's Claude panel; the At limit badge and the limit warning clear as the data refreshes (about 4 s, loops). |
